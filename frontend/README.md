# ai_tools_verse

AIVerse Mobile App — Flutter implementation of the AI tools discovery platform.

## 📱 About

AIVerse is a directory and discovery platform for AI tools, allowing users to search, browse, compare, and bookmark AI products across multiple categories. This mobile app brings the full tool-discovery experience to iOS and Android.

## 🚀 Features

- Browse trending and featured AI tools
- Explore tools by category
- Search across 1,000+ listed tools
- View detailed tool profiles
- Save/bookmark favorite tools
- Submit new tools for listing
- Dark mode only (v1.0)

## 🎨 Design

- **Theme:** Dark mode only with purple-to-pink gradients
- **Font:** Inter (via Google Fonts)
- **Platform:** iOS & Android (Flutter)

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

- Flutter SDK (^3.11.5)
- Dart SDK (^3.11.5)
- iOS Simulator or Android Emulator

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to project directory
cd ai_tools_verse

# Install dependencies
flutter pub get

# Run the app
flutter run
```
